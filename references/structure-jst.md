# JST(さきがけ・創発的研究支援事業)の構成

対象: さきがけ研究提案書、創発的研究支援事業の研究提案書。**公募要領と募集領域(さきがけの場合)の記載を正とする**。科研費との最大の違いは、審査の中心が「課題」ではなく**「人と構想」**にあること。

## 評価観点(科研費との差分)

1. **挑戦性・卓越性**: 成功が保証された堅実な計画より、成功すれば分野を変える大胆な構想が評価される。「できることの積み上げ」に読まれたら負け。
2. **構想の独自性が研究者本人に根ざしているか**: なぜ「あなたが」やるのか。経歴・独自技術・視点との必然的な結びつき。
3. **さきがけ**: 領域の「戦略目標・領域のねらい」との整合。領域アドバイザー(専門近接〜専門外)が読む。
4. **創発**: 破壊的イノベーションの種になりうるか。10年スケールの野心。
5. **面接前提**: 書面は面接に呼ばれるための文書。詰め込みすぎず、聞きたくなる構想を鮮明に。

## 書き方の調整(科研費モードからの変更点)

- **ビジョン先行**: ファネル構造の「見返り(payoff)」を冒頭近くに引き上げる。「この構想が実現した世界」を先に見せ、そこから逆算して現在の問いに降りる。
- **挑戦性の明示**: 「本構想の挑戦的な点は〜であり、成功すれば〜が初めて可能になる」を明示的に1段落置く。リスクを隠さず、リスクに挑む理由と勝ち筋(独自の武器Z)を示す。
- **堅実パートとの二層構造**: 全部が夢物語では実現可能性を疑われる。「確実に到達できる中間成果」と「挑戦的な最終目標」を分けて書き、前者だけでも価値があることを示す。
- **自分を書く**: 科研費より一人称の比重を上げる。着想に至る自分の発見・失敗・技術蓄積を具体的に。「申請者は〜を世界に先駆けて見出した(文献)。この経験から〜という着想を得た」。
- **さきがけの領域適合**: 領域のねらいの文言を引用し、自分の構想がその文言のどこに貢献するかを1段落で明示する。こじつけは領域アドバイザーに見抜かれるため、整合が弱い場合はユーザーに領域選択を再考するよう伝える。

## セクション構成の目安(様式により変動)

1. **研究構想**(全体の30〜40%): ビジョン → 問い → 挑戦性 → 独自アプローチ
2. **研究計画**: 中間到達点と最終目標の二層構造、期間内マイルストーン
3. **研究者としての強み・実績**: 構想と紐づけた実績(列挙禁止、thinking.md 7の遂行能力の書き方に同じ)
4. **将来展望**: 期間終了後にどう展開するか(創発では特に重視)

## 文体の調整

style.md の規範は全て適用。ただし空洞語のうち「挑戦的」は、この種目では**中身(何がなぜ難しく、なぜ自分は挑めるか)を伴えば**積極的に使ってよい。
