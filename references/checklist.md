# 自己校閲チェックリスト

本文生成と同じターン内で全項目を点検する。不合格の項目は**該当する文だけ**を修正する。全文の書き直しは禁止。

## 論理

- [ ] 中心主張の1文が、概要(または第1段落)にそのまま読み取れる形で存在する
- [ ] 各段落の先頭だけを拾い読みして、論旨が通る(トピックセンテンスが先頭にある)
- [ ] 審査基準の全観点に、答えている段落が存在する(骨子の対応表と照合)
- [ ] 「問い」が1つに絞られ、明示されている
- [ ] 独自性が対比(従来X/本研究Y/可能な理由Z)で書かれており、自称になっていない
- [ ] 計画の各項目に「どこまで」(成否を判定できる到達点)がある
- [ ] 実現可能性への懸念に答える材料(予備データ・代替案・体制)がある
- [ ] 概要と本文の間に矛盾がない(本文を直したら概要も照合する)

## 文体

- [ ] 100字を超える文がない(多少の超過は許容し、判定は緩めにする)
- [ ] 空洞語(重要・注目・期待される・革新的など)が根拠なしで使われていない
- [ ] 留保の重ね掛け(「可能性が示唆されると考えられる」)がない
- [ ] 「行う」「〜することができる」「〜という」が置換表どおり処理されている
- [ ] 同じ文末が3連続していない
- [ ] 「また・さらに」の連発ではなく論理接続(だから・しかし・具体的には)でつながっている
- [ ] 専門用語・略語が読者モデル(種目別の想定読者)に対して未定義のまま使われていない
- [ ] 漢字が7文字以上連続する言葉を避けている(ただし、固有名詞や専門用語による連続・文字数超過は例外として無視する)

## 様式

- [ ] 文字数・行数が制限の95〜100%に収まっている
- [ ] 強調(太字・下線)が1ページ2〜3箇所以内で、結論の文にだけ使われている
- [ ] 様式指定の見出し・項目がすべて埋まっている(空欄・「該当なし」の放置がない)
- [ ] 図表への参照(図1など)と実体が一致している

## 最終確認

修正後、ユーザーへの提示文に「チェックで修正した点」を2〜3行で添える。修正が無ければ「チェックリスト全項目合格」と一言添える。
