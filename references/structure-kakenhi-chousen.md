# 科研費 挑戦的研究(萌芽・開拓)の構成

対象: 挑戦的研究(萌芽)・挑戦的研究(開拓)の「研究計画調書」。様式は年度で微修正されるため、**ユーザー提供の最新様式・公募要領を正とする**。以下は現行様式の標準構成。

科研費の一種目だが、審査の中心軸が基盤・若手とは異なる。基盤が「堅実な問いへの確実な回答」を評価するのに対し、挑戦的研究は**「学術の体系・方向を大きく変革・転換させる、あるいは既存の概念・体系を覆す潜在性(=挑戦性)」**を軸に評価する。「できることの積み上げ」に読まれた時点で不利になる点はJST(structure-jst.md)と同じだが、様式・分量・評定要素は科研費固有。

## 萌芽と開拓の違い(執筆前に確定させる)

| | 萌芽(exploratory) | 開拓(pioneering) |
|---|---|---|
| 位置づけ | 挑戦的な着想の**芽を見極める**探索段階 | 変革をもたらす研究を**本格的に展開**する段階 |
| 規模・期間の目安 | 小規模・短期(数年) | 大規模・中長期 |
| 様式の分量 | 簡潔(コンパクトな様式) | 基盤S級に厚い |
| 求められる核 | 筋の良い挑戦的アイデアと最小限の検証設計 | 変革の道筋・体系構築の全体像 |

**規模・期間・様式ページ数は公募要領の最新値を正とする**(このスキルに固定値を書かない)。萌芽は「面白いが本当か分からない種を、なぜ今試す価値があるか」を鋭く一点に絞る。開拓は「変革の全体構想と、それを担える体制」を厚く描く。

## 評定要素(段落対応表はこの軸で作る)

公募要領の評定要素を正とするが、標準的には次の重みで読まれる。

1. **挑戦性(最重要)**: 学術の体系・方向を大きく変革・転換する、または既存の概念・体系を覆す潜在性。独自性・創造性、これまでの研究の展開とは異なる**新しい価値の創出**が期待できるか。
2. **学術的独自性・創造性**: 問いと着想が既存研究の延長ではないこと。
3. **実現可能性**: 挑戦的でありながら、なぜ**この計画・この人**なら成算があるか(予備知見・独自技術)。
4. **研究遂行能力・研究環境**: 挑戦を担える実績・準備。

挑戦性と実現可能性はトレードオフに見られやすい。両立の鍵は「挑戦の核は大胆に、しかし勝ち筋(独自の武器Z)と最初の検証は具体的に」書くこと。

## セクション別の書き方

### 概要(冒頭の囲み)

申請書全体の縮図。基盤と違い、**冒頭で「何を覆す/変革する挑戦か」を先に見せる**。背景1文 → 覆す対象・変革像1〜2文 → 問い1文 → アプローチと勝ち筋2文 → どこまで見極める/切り拓くか1文。審査委員の第一印象がここで決まる。本文完成後に整合を再確認する。

### (1) 学術的背景と「問い」

thinking.md のファネル構造(既知→未知→問い)を使うが、**未知を「まだ誰も踏み込んでいない/常識が通用しない領域」として際立たせる**。核心をなす学術的「問い」は疑問文または「〜か」の形で明示的に1つ、太字で書く。挑戦的研究では問いそのものが挑戦的(前提を疑う、分野の壁を越える)であることが望ましい。

### (2) 本研究の「挑戦性」— なぜ挑戦的か(この種目の心臓部)

**挑戦性を独立の1段落で明示的に説明する。ここが空欄・曖昧だと採択されない。** 次の3点を必ず書く。

- **何を覆す/変革するか**: 既存のどの概念・体系・方向を、どう転換させる可能性があるか。「新しい価値の創出」を具体語で。
- **なぜ難しく、なぜ今まで手が付かなかったか**: 技術的・概念的な障壁。ここを書くとハイリスクの正体が伝わる。
- **なぜ自分/この計画なら挑めるか(勝ち筋Z)**: thinking.md の対比3点セット(従来X/本研究Y/可能な理由Z)のZを厚く。独自技術・予備観察・視点が障壁を突破する根拠。

空洞語の「挑戦的」は、**この中身(何がなぜ難しく、なぜ自分は挑めるか)を伴う場合のみ**使ってよい(style.md の原則の例外。JSTと同じ扱い)。

### (3) 目的と、何をどこまで明らかにするか

- 目的は問いへの答え方として書く。挑戦性を薄めて堅実な話に着地させない。
- **萌芽**: 研究項目を絞り、「この種が本物かを見極める最小の検証(go/no-go の判定基準)」を具体的に。全部を成し遂げる必要はなく、「見極め」の設計の鋭さで勝負する。
- **開拓**: 研究項目2〜3本で変革の道筋を描く。各項目を「何を/どのように/どこまで」で書き、**「どこまで」に成否を判定できる到達点**(数値・比較対象)を必ず入れる。
- **二層構造(実現可能性の担保)**: 「確実に到達できる中間成果」と「挑戦的な最終目標」を分けて書き、前者だけでも学術的価値があることを示す(structure-jst.md と同じ考え方)。
- 高リスク項目には代替案・撤退条件を1文添える。挑戦的研究では**リスクを隠すより、リスクを認識し管理していること**が信頼につながる。

### (4) 着想の経緯と位置づけ

- 着想の経緯は挑戦性の説得力を支える。**自分の過去の発見・観察・違和感から、なぜこの挑戦に至ったか**の因果を2〜4文で。ここが強いほど「なぜあなたが」に答えられる。
- 動向は網羅レビューではなく、本研究が既存研究の**延長線上にないこと**を示すための最小限の地図。「主流はAへ進むが、本研究はそれと異なるBの可能性を拓く」の形で位置づける。

### (5) 準備状況・遂行能力

- 予備データ・予備観察が「挑戦は無謀ではない」ことの最強の根拠。挑戦的な主張ほど、それを裏づける小さな実証を一つ示す。
- 遂行能力は業績の列挙ではなく、**挑戦の各要素を担える証拠**として業績を選ぶ。「この転換に必要なY法は申請者が確立した(文献n)」の形で計画と紐づける(structure-kakenhi.md と同じ原則)。

## 基盤モード・JSTモードとの差分(混同しないため)

- **対 基盤(structure-kakenhi.md)**: 審査の第一軸が「学術的重要性」ではなく「挑戦性(変革・転換の潜在性)」。堅実さより大胆さを前面に。ただし様式・評定要素の枠組みは科研費。
- **対 JST(structure-jst.md)**: 挑戦性重視・二層構造・一人称の比重という発想は共通。違いは、JSTが「人と構想」中心・面接前提なのに対し、挑戦的研究は**書面審査(総合審査)完結**で、科研費様式の「問い・目的・方法・準備」の型に挑戦性を載せる点。ビジョンの語りすぎより、覆す対象と勝ち筋の明確さを優先する。

## 分量配分の目安

背景・問い 20% / **挑戦性の明示 20%** / 目的・方法(二層構造) 35% / 着想・位置づけ 15% / 準備・遂行能力 10%。基盤と違い「挑戦性」に独立の枠を確保するのが要点。萌芽は全体を圧縮し、挑戦性と見極め設計に集中させる。
