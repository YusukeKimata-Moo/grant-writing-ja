# 日本語文体規範

執筆時はこの規範に従う。`examples/` にユーザーの過去申請書があれば、そちらの語彙・リズムをこの規範より優先する。

## 文の規則

- **一文一義。** 1文に主張は1つ。目安は40〜80字。100字を多少超過する程度であれば許容し、判定は緩めにする。
- **主語と述語を近づける。** 間に長い修飾節を挟まない。修飾節が長いなら文を分ける。
- **文末は「だ・である」体。** 体言止めは図表キャプション以外で使わない。
- **同じ文末を3連続させない。**「〜である。〜である。〜である。」はリズムで読み手を失う。
- **並列は3つまで。** 4つ以上並べたくなったら、重要な2〜3個に絞るか箇条書きにする。
- **漢字の連続制限と例外**: 漢字が7文字以上連続する言葉は読みにくいため可能な限り避ける。ただし、固有名詞（例: 「日本学術振興会育志賞」など）や専門用語については、この制限を無視してそのまま維持する。

## 冗長表現の置換表(執筆中に適用する)

| 冗長 | 置換 |
|---|---|
| 〜することができる | 〜できる |
| 〜を行う / 〜を実施する | 〜する(動詞に戻す。例: 解析を行う→解析する) |
| 〜という○○ | 〜(「という」は原則削除) |
| 〜に関して / 〜について | 〜は / 〜を(助詞で言えるなら助詞) |
| 〜的な側面がある | (具体的に言い直す) |
| 〜と考えられる(根拠を直前に示した場合) | 断定する |
| 〜などの / 〜といった | (例が尽きているなら削除) |
| 非常に / 極めて / 大いに | (削除するか、数値で示す) |

## 空洞語の禁止

次の語は、直後に具体的根拠(数値・文献・データ)を伴わない限り使わない: **重要である、注目されている、期待される、革新的、包括的、飛躍的、独創的、画期的**。

これらは主張であって根拠ではない。「独創的である」と書く代わりに、何と比べて何が違うかを書けば、読み手が独創的だと判断する。

## 断定と留保の使い分け

- 自分のデータ・確立した事実 → 断定(「〜である」「〜を示した」)
- 自分の解釈・仮説 → 1段階の留保(「〜と考えられる」「〜が示唆される」)
- **留保の重ね掛け禁止**:「〜の可能性が示唆されると考えられる」→「〜の可能性がある」
- 申請書の計画部分は意思で書く:「〜したいと考えている」→「〜する」

## AI的文体の回避

- 情報量ゼロの導入文を書かない:「近年、○○分野は急速に発展している」型の文は、後続の未知・問いに直結する場合のみ許す。
- 「また、」「さらに、」「加えて、」の連発で段落をつながない。論理関係(だから・しかし・具体的には)で接続する。
- 箇条書きに逃げない。申請書の本文は論理の流れを示す散文が基本。箇条書きは計画項目・体制など列挙が本質的な箇所のみ。
- 総花的なまとめ文(「以上のように本研究は多方面に貢献する」)を書かない。貢献は具体的に1〜2点を深く書く。

## 強調(太字・下線)

- 使うのは**審査委員に拾い読みされたい結論の文**のみ。1ページに2〜3箇所まで。
- 段落のトピックセンテンスか、審査基準への直接の答えに限る。飾りとして使わない。

## NG→OK 対比例

**1. 空洞な重要性 → 未知の特定**
- NG: 「タンパク質Xの機能解明は極めて重要であり、多くの研究者が注目している。」
- OK: 「タンパク質Xの結合相手は同定されているが、結合が細胞内のどこで起こるかは分かっていない。」

**2. 留保の重ね掛け → 根拠+断定**
- NG: 「この手法は有効である可能性が示唆されると考えられる。」
- OK: 「予備実験では検出感度が従来法の10倍であり(図1)、本手法は有効である。」

**3. 長文 → 一文一義**
- NG: 「本研究では、これまで困難であったXの計測を、申請者が開発したY法を用いることで実現し、その結果得られるデータをもとにZの機構を解明することを目的とする。」
- OK: 「本研究の目的はZの機構解明である。鍵となるXの計測は従来困難だったが、申請者が開発したY法により実現できる。」

**4. 自称の独自性 → 対比による独自性**
- NG: 「本研究のアプローチは独創的であり、国内外に類を見ない。」
- OK: 「従来研究は集団平均の挙動を扱ってきた。本研究は1分子ごとの追跡により、平均に埋もれていた少数状態を直接捉える点で異なる。」

**5. 総花的な波及効果 → 具体的な一点**
- NG: 「本研究の成果は、基礎科学の発展のみならず、医療・産業など幅広い分野への波及効果が期待される。」
- OK: 「Xの機構が分かれば、現在スクリーニングに頼っている阻害剤設計を構造ベースに置き換えられる。」
