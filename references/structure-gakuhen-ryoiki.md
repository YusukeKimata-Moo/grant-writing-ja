# 学術変革領域研究(A)(B) 領域提案(計画研究)の構成

対象: 学術変革領域研究(A)・(B)の**新規領域提案**。領域代表者が書く「領域計画調書」と、各計画研究代表者が書く「計画研究課題」の両方を含む。様式は年度で微修正されるため、**ユーザー提供の最新様式・公募要領を正とする**。

これは他の科研費と執筆者・スケールが根本的に異なる。基盤・挑戦的研究・公募研究が**一人(または一課題)の研究**を提案するのに対し、領域提案は**複数の研究者が集まって新しい学術領域そのものを立ち上げる**設計図。評価されるのは個々の研究の質ではなく、**「領域として何を変革するか」と「その体制」**。

## (A)と(B)の違い(執筆前に確定させる)

| | (A) | (B) |
|---|---|---|
| 位置づけ | 変革を**本格的に牽引**する大規模領域 | 変革の**芽を育てる**萌芽的・挑戦的な小規模領域 |
| 規模・期間の目安 | 大規模・長期(5年) | 小規模・中期(3年) |
| 公募研究 | あり(途中から受け入れ) | なし |
| 求められる核 | 変革の全体像と強固な連携体制 | 変革の潜在性と、少数精鋭の挑戦 |

規模・期間・計画研究数・様式ページ数は**公募要領の最新値を正とする**(固定値を書かない)。(A)は「領域として分野を作る/変える」全体像と体制を厚く。(B)は「まだ小さいが化ける芽」であることと、挑戦性を鋭く。

## 評定要素(段落対応表はこの軸で作る)

領域・年度の評定要素を正とするが、標準的には次を軸に読まれる。

1. **学術的変革の potential(最重要)**: 既存の学問分野・体系を、この領域がどう変革・転換・創出するか。単一分野の深掘りでなく、**分野を越えた融合による新しい学術の創出**。
2. **領域設定の妥当性・必然性**: なぜ「今」「この構成メンバー」で領域を作るのか。個々の研究の寄せ集めでないこと。
3. **研究項目と計画研究の設計**: 研究項目(A01/B01…)が変革の論理に沿って過不足なく配置され、計画研究がそれを担うか。
4. **連携・融合の実質**: 計画研究間の有機的連関。「並置」でなく相互に不可欠な関係。
5. **体制・運営・波及**: 領域代表者のリーダーシップ、若手育成、国際活動、(Aは)公募研究の受け入れ設計、アウトリーチ。

## パート1: 領域全体の構想(領域代表者が書く)

### 領域が目指す変革(冒頭・最重要)

**「この領域が成功したら、どの学問分野の何が変わるか」を最初に見せる**。既存分野の限界 → その壁を越える融合のアイデア → 生まれる新しい学術、の順。thinking.md のファネル構造を「領域スケール」で使う。

### 領域設定の必然性

なぜ今か(分野の機が熟した/技術が揃った)、なぜこのメンバーか(この融合はこの布陣でしか起きない)。**個々に優れた研究者の寄せ集めに読まれたら負け**。メンバー間に既存の予備的連携や共通の問いがあれば示す。

### 研究項目の設計

変革の論理から**研究項目(A01, A02, B01…)を導く**。各項目が「変革のどの側面を担うか」を1行で言えること。項目間の依存・連関を図で示すと強い。項目は変革の物語に沿って並べ、網羅性のためのカタログにしない。

### 連携・融合・体制・波及

- **融合の仕組み**: 計画研究が具体的に何を交換・共同するか(試料・データ・手法・概念)。共通基盤(コアファシリティ、データ共有、共同解析)があれば明示。
- **運営**: 領域代表者のマネジメント、領域会議、若手育成、国際連携。
- **(A のみ)公募研究の設計**: どんな公募研究を、どの研究項目で受け入れ、領域をどう広げるか。
- **波及**: 領域終了後に学術・社会に何が残るか。

## パート2: 計画研究課題(各計画研究代表者が書く=計画班としての申請)

各計画研究の調書は、基盤研究に似た「問い・目的・方法・準備」の型で書くが、**単独最適でなく領域最適**が原則。基盤モード(structure-kakenhi.md)との差分は次の通り。

- **領域構想の中での役割を冒頭で明示**: 「本計画研究は、領域の研究項目○○を担い、〜を明らかにすることで領域全体の変革に寄与する」。
- **担当研究項目への責任**: 領域構想が自課題に期待する到達点を、自分の言葉で引き受ける。
- **他の計画研究との連携**: 誰に何を渡し、誰から何を受け取るか(データ・試料・手法)。この相互依存が「融合」の実体。
- **自課題の学術的独自性・実現可能性**: ここは基盤と同じ観点(thinking.md の対比3点セット、予備データ、遂行能力)。
- **(A のみ)公募研究との接続**: 自課題が受け入れる公募研究にどんな貢献を期待するか。

領域全体の構想(パート1)と各計画研究(パート2)の**用語・到達点・連携関係が矛盾しないこと**を、書き終えた後に必ず突き合わせる。

## 他モードとの差分(混同しないため)

- **対 公募研究(structure-gakuhen-koubo.md)**: 公募研究は「既存領域への参加」、こちらは「領域そのものの提案」。執筆者が領域代表者/計画研究代表者で、上位に自分たちの構想がある。
- **対 基盤(structure-kakenhi.md)**: 計画研究課題は型は似るが、評価軸が「単独の研究の質」でなく「領域変革への貢献と連携」。
- **対 挑戦的研究(structure-kakenhi-chousen.md)**: (B)は挑戦性の発想を共有するが、**個人でなくチームで分野を変革する**点が決定的に違う。

## 分量配分の目安

領域全体の構想(変革ビジョン・必然性・項目設計) 40% / 連携・体制・波及 20% / 各計画研究課題 (残り、課題数で按分) 40%。(B)は全体を圧縮し、変革の芽と挑戦性・少数連携に集中させる。
